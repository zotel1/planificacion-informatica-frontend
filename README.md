# 🐱‍👤 PokeAPI - Frontend

Frontend de la aplicación **PokeAPI**, desarrollado utilizando **HTML, CSS y JavaScript**.

El objetivo del proyecto es desarrollar una aplicación web que permita consultar, explorar y visualizar información sobre diferentes Pokémon mediante el consumo de una **API REST**.

## 🚀 Tecnologías

* **HTML5** — estructura de la aplicación.
* **CSS3** — estilos, diseño y responsive.
* **JavaScript** — lógica, interacción con el usuario y consumo de la API.
* **Fetch API** — comunicación con la API REST.
* **Git / GitHub** — control de versiones y trabajo colaborativo.

## 📋 Funcionalidades

La aplicación permitirá:

* 🔎 Buscar Pokémon.
* 📋 Visualizar un listado de Pokémon.
* 🎴 Consultar información detallada de cada Pokémon.
* ⚡ Mostrar tipos, habilidades y estadísticas.
* 🖼️ Visualizar imágenes de los Pokémon.
* 🔀 Navegar entre las diferentes funcionalidades de la aplicación.
* 📱 Contar con un diseño adaptable a diferentes tamaños de pantalla.

## ⚙️ Instalación

Clonar el repositorio:

```bash
git clone <URL_DEL_REPOSITORIO>
```

Ingresar al directorio del frontend:

```bash
cd frontend
```

Como se trata de un proyecto desarrollado con HTML, CSS y JavaScript puro, no es necesario instalar frameworks para ejecutarlo.

Se recomienda utilizar **Visual Studio Code** junto con **Live Server** para ejecutar el proyecto durante el desarrollo.

## 🌿 Flujo de trabajo con Git

Cada integrante deberá trabajar en una rama independiente para evitar conflictos entre los cambios.

Ejemplo:

```bash
git checkout -b feature/pokemon-list
```

Una vez terminada la funcionalidad:

```bash
git add .
git commit -m "feat: agregar listado de pokemon"
git push origin feature/pokemon-list
```

Luego se realizará un **Pull Request** hacia la rama principal.
